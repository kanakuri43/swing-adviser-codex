# Data Sources

AGENT.md の要約から分割した、外部データ取得元に関する決定事項。
「どこからデータを取るか」を集約し、「取ったデータをどう分析するか」は [`technical-analysis.md`](./technical-analysis.md) を参照。
Non-negotiable rules・優先順位は AGENT.md 側が正であり、本ファイルの内容と矛盾する場合は AGENT.md を優先する。

## Market scope
対象は日本株。

スキャン対象(仮決定): 東証上場の国内普通株のみ。ETF、ETN、REIT、優先株、外国株扱い、整理/上場廃止銘柄等は当面対象外とするが、将来含められるよう設定・フィルタ可能な構造にし、勝手に固定仕様へしない。

銘柄マスタ(コード・銘柄名・市場区分)の取得元(仮決定): JPX公式の上場銘柄一覧(無料CSV/Excel)を定期ダウンロードして更新する。ファイル形式変更に備え、取得処理は Infrastructure 層に隔離する。

信用売り候補では、テクニカルな `Short Entry` と「実際に売建可能か」を別情報として扱う。
信用取引対象区分・売建可否・規制情報の取得元(仮決定): JPX公式の信用取引銘柄・貸株銘柄一覧(無料CSV)を定期取得する。取得不能時は「不明」として扱い、売建可能と推測表示しない。

## Price data
株価取得元は交換可能な抽象化を用いる。日足の最低項目は `Date/Open/High/Low/Close/Volume`。

取得元(仮決定): Yahoo Finance 非公式 chart API (`query1.finance.yahoo.com/v8/finance/chart/{code}.T`) を C# から HttpClient で直接呼び出す。
- レスポンスの `close`（未調整）と `adjclose`（分割・配当調整済み）を両方保存する。
- テクニカル分析（指標計算・シグナル判定）は原則 `adjclose` を基準に行う。`close` は表示・約定価格参考用に残す。
- 初回/不足分取得の対象期間は直近2年を仮値とする。既存データがあれば不足分のみ追加取得（差分更新）。
- 非公式APIのため、エンドポイント仕様変更・レート制限・アクセス遮断のリスクを前提に、取得処理は Infrastructure 層に隔離し、抽象化（インターフェース）越しに差し替え可能にする。

考慮:
- 株式分割・併合、調整後株価
- 欠損、訂正データ
- API rate limit、timeout、network error
- 企業アクションによる不連続のサイン誤検出防止

## Fundamental data
ファンダメンタル情報取得元(仮決定): Yahoo Finance の企業情報エンドポイント(非公式、株価取得と同じソース系統)から PER/PBR/時価総額等の構造化データを取得し、アプリ側で保持する。決算詳細・ニュース・業績予想等の非構造化情報は Codex CLI(AI)自身の調査に委ねる（詳細は [`ai-analysis.md`](./ai-analysis.md) を参照）。取得不能時は当該項目を欠損として扱い、AI 結果を無効にしない。

## Date/time
基準は日本時間 (`Asia/Tokyo` / JST)。
「分析日」「価格データ日」「約定日時」は別概念として扱う。
土日だけでなく日本市場の休場日を扱える構造にする。
15:30 を過ぎただけでデータ確定済みと断定しない。
DB 保存時は日時のタイムゾーンの意味を曖昧にしない。
