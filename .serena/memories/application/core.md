# Application Layer
- `src/SwingAdviser.Application`; references Domain only.
- Owns use-case orchestration. Target scope includes market-data update, universe scan/candidate extraction, held-position reevaluation, AI checks, and manual execution registration; do not infer that all are implemented.
- Currently implemented boundaries: `TradingWorkspaceService`/`ITradingWorkspaceRepository` for candidate/position/execution reads and explicitly user-confirmed execution changes; `AllInstrumentScanService` for PIT-effective identifier/master universe filtering, one identity-bound indicator calculation per verified instrument input, separate Long/Short candidate scoring, progress/cancellation, and per-instrument failure isolation. Held-position reevaluation, AI execution, market-data update, and Infrastructure scan input/result persistence adapters remain unimplemented.
- Keep infrastructure behind abstractions; use async/cancellation for I/O workflows and preserve explicit user confirmation boundaries for executions.
